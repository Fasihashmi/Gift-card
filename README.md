# gift-card
A gift card that you can send to your friends and loved ones.

## Deploy on GitHub Pages

This repository is a static site (`index.html`), so you can deploy it directly with GitHub Pages.

1. Push your latest changes to the `main` branch.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, set:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`
   - **Folder**: `/ (root)`
4. Save and wait for the Pages URL to be generated.

## Verify deployment

After the URL is available:

- Open the site URL.
- Confirm Bootstrap styling loads.
- Confirm animations run.
- Confirm modal interactions work.
